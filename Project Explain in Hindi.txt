## **1. 📌 Project Introduction (परिचय)**

**Customer Churn Analysis** एक Data Analytics Project है, जिसमें हम यह समझते हैं कि कितने customers किसी कंपनी की services लेना बंद कर रहे हैं और ऐसा करने के पीछे क्या कारण हैं।

इस प्रोजेक्ट का मुख्य उद्देश्य customer छोड़ने के कारणों को पहचानना और कंपनी को ऐसे सुझाव देना है जिससे customers को लंबे समय तक बनाए रखा जा सके।

**Example:**

मान लीजिए एक Telecom Company के पास 10,000 customers हैं। उनमें से 2,000 customers ने अपनी services बंद कर दीं।

तो हमें पता लगाना होगा:

- कितने customers कंपनी छोड़ रहे हैं?
- Customers कंपनी क्यों छोड़ रहे हैं?
- किस age group के customers ज्यादा churn कर रहे हैं?
- कौन-सा subscription plan सबसे ज्यादा churn हो रहा है?
- Customers को रोकने के लिए क्या करना चाहिए?

## **6. 🧮 Important Formulas**

**Customer Churn Rate**

\\[ Churn\ Rate = \frac{Customers\ Lost}{Total\ Customers}\times100 \\]

Example:

- Total Customers = 1,000
- Customers Lost = 200

\\[ Churn\ Rate = \frac{200}{1000}\times100=20\\% \\]

Result: 20% Churn Rate

**Customer Retention Rate**

\\[ Retention\ Rate = \frac{Customers\ Retained}{Total\ Customers}\times100 \\]

**Average Monthly Charges**

\\[ Average = \frac{Total\ Monthly\ Charges}{Total\ Customers} \\]

## **7. 💻 SQL Practical Queries**

**Query 1: Total Customers**

```
SELECT COUNT(CustomerID) AS Total_Customers
FROM Customers;
```

**Query 2: Churned Customers**

```
SELECT COUNT(*) AS Churn_Customers
FROM Customers
WHERE Churn = 'Yes';
```

**Query 3: Churn by Gender**

```
SELECT Gender,
       COUNT(*) AS Total_Customers
FROM Customers
WHERE Churn = 'Yes'
GROUP BY Gender;
```

**Query 4: Churn by Contract**

```
SELECT Contract,
       COUNT(*) AS Churn_Count
FROM Customers
WHERE Churn = 'Yes'
GROUP BY Contract;
```

**Query 5: Average Monthly Charges**

```
SELECT AVG(MonthlyCharges)
AS Average_Monthly_Charges
FROM Customers;
```

```
Total Customers =
COUNTROWS(Customers)
```

```
Churn Customers =
CALCULATE(
    COUNTROWS(Customers),
    Customers[Churn] = "Yes"
)
```

```
Churn Rate =
DIVIDE(
    [Churn Customers],
    [Total Customers],
    0
) * 100
```
